# Настраиваемые API распознавания и очистки

Этот документ описывает реализованную конфигурацию и ограничения адаптеров. Он не является каталогом моделей или сравнением провайдеров. Общая структура приложения описана в [архитектуре](../ARCHITECTURE.md), пользовательская настройка — в [README](../../README.md).

## Конфигурация

`TranscriptionConfiguration` хранит обязательный endpoint распознавания, необязательный endpoint очистки, её переключатель, код языка и настройки обработки. Endpoint включает тип провайдера, базовый URL, точный идентификатор модели и протокол распознавания.

URL и модели вводятся вручную. Предустановленные значения дают стартовую конфигурацию и не ограничивают выбор. Можно использовать один API с двумя моделями или отдельные URL и ключи. Очистка по умолчанию выключена.

Ключи находятся только в macOS Keychain. Запись привязана к провайдеру и нормализованному базовому URL. Смена адреса требует подходящего ключа; в истории и настройках секреты не сериализуются. Стандартная запись ключа Gemini сохраняется при миграции.

## Маршруты

| Режим | Формат | Маршрут |
| --- | --- | --- |
| Файловое распознавание | multipart: `file`, `model`, необязательный `language` | `audio/transcriptions` |
| Аудиочат | JSON: модель, инструкция и `input_audio` с base64 WAV | `chat/completions` |
| Нативное распознавание | FLAC через Gemini Interactions | `v1beta/interactions` |
| Старый нативный API | FLAC через Generate Content | `v1beta/models/<model>:generateContent` |
| Текстовая очистка | Текстовый чат либо Generate Content для Gemini | соответствующий текстовый маршрут |

Адаптер добавляет маршрут к базовому URL, который уже включает версию API. Идентификаторы моделей передаются значениями параметров. HTTPS обязателен; HTTP допускается для localhost. URL с учётными данными, query или fragment отвергается.

Совместимый файловый адаптер отправляет минимальный набор полей. Словарные замены применяются локально; неподтверждённые словарные параметры в файловый API не добавляются. Для аудиочата и Gemini словарь передаётся как подсказка.

Провайдер должен поддерживать выбранный контракт. Формат `input_audio: {data, format: "wav"}` не доказывает совместимость любого аудиочата. Обнаруженные ответы вместо расшифровки и обрезанный текст отвергаются, но независимой проверки точности аудиочата нет.

## Цепочка обработки

1. При начале записи координатор сохраняет копию конфигурации в `SessionMeta`.
2. Аудио записывается в CAF до его передачи в API. Для отправки готовится WAV или FLAC вне главного потока.
3. `TranscriptionService` выбирает адаптер по сохранённой конфигурации и получает исходную расшифровку.
4. Исходный текст сохраняется до дополнительной обработки.
5. Если очистка выключена, выполняются только локальные словарные замены. Если включена — отдельная текстовая модель получает инструкции очистки.
6. Результат сравнивается с исходным текстом. При ошибке, превышении времени или отклонении возвращается исходная расшифровка с локальными заменами.
7. Координатор передаёт текст общему механизму вставки и обновляет историю.

Бюджет ожидания очистки — 1,5 секунды. После трёх отклонений за сутки текущая очистка выключается с уведомлением. Согласование тона включается отдельно и использует категорию целевого приложения. Семантическую точность модели нельзя гарантировать проверкой сходства.

## Языки и Live

Автоматический язык означает отсутствие параметра `language`. Явный код сохраняется с записью и отправляется в совместимый API; поддержка кода зависит от модели. Gemini использует автоматическое определение.

Язык интерфейса хранится отдельно: русский по умолчанию, английский по выбору, применение после перезапуска. Перевода расшифровки нет.

Нативный Live включается только для поддерживаемой конфигурации Gemini с автоматическим языком и выключенной очисткой. Его параметры также берутся из копии конфигурации сеанса. Выбор совместимого API не запускает поток в другом сервисе.

## Ошибки и повторы

Для совместимого API 401 означает ошибку ключа, 402 — недостаточный баланс, 429 — временное ограничение, 5xx — ошибку сервера. Поддерживается один ограниченный повтор по `Retry-After`; сетевые ошибки обрабатываются общей цепочкой. Ошибки URL, модели и параметров показываются с деталями без ключа.

Очередь использует исходную конфигурацию записи и не меняет провайдера автоматически. Блокировка одного набора ключей не останавливает другие. Повторы запускаются при восстановлении сети, запуске приложения, изменении ключа или явном действии пользователя. Очередь сохраняет результаты в истории без автоматической вставки.

«С текущей моделью» создаёт новую запись с текущими настройками, сохраняя прежний результат. Старые записи без конфигурации получают неизменяемую исходную конфигурацию миграции.

## Проверка

[APIContractChecks.swift](../../JotCore/Tests/JotCoreTests/APIContractChecks.swift) проверяет маршруты, multipart и JSON, заголовки, язык, отмену, ошибки, отключённую очистку, возврат исходного текста, сохранённые настройки, очередь и локализацию. Запуск: `./scripts/verify-api-contract.sh`.

Эти проверки используют подставные ответы и не выполняют платных запросов. Совместимость конкретного API, качество распознавания/очистки, длительность запросов и поведение приложения при вставке проверяются отдельно. Локальные модели, новые live-протоколы, перевод речи, диаризация и асинхронные задания в эту реализацию не входят.
